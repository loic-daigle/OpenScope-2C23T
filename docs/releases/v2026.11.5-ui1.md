A modern interface for the F2C23T, built on OpenScope v2026.11.5. Measurement, oscilloscope and generator behaviour is unchanged; this release is about how everything looks and reads.

## Which file to flash

| Your device | File |
|---|---|
| Came with or runs stock firmware **2.1.0** (HW4.0) | `F2C23T-v2026.11.5-ui1-HW4.0-08007000.bin` |
| Older hardware (never had 2.1.0) | `F2C23T-v2026.11.5-ui1-08008000.bin` |

Flash with the built-in bootloader: turn the device off, hold `MENU`, press power, connect USB and copy the `.bin` to the drive that appears. The bootloader is never modified, so you can always go back the same way. Saved settings and calibration are kept.

## What's new

- **Modern look everywhere:** a flat dark theme, rounded cards, anti-aliased Inter type, Lucide-style icons, proper unit symbols (Ω, µ, °C) and one colour per tool.
- **Multimeter:** a large reading with a bar graph (centred on zero in REL), a MIN / AVG / MAX row, HOLD / REL / AUTO tags, and a red outline above 30 V AC or 60 V DC. Continuity shows a green "Connected" card (below 50 Ω), and Live Wire has its own card.
- **Main menu:** a 2×2 grid of tool cards, navigated with the arrow keys including up/down.
- **Settings:** tiles with icons and level meters, an info card (version, hardware revision, free USB space), and rounded dialogs for bootloader export and factory reset.
- **Oscilloscope:** a dotted graticule, channel tags, a trigger-level tag with an edge icon, measurement pills, a pill bottom bar, and modern parameter chips. The Analytical / Math, FFT and Bode views are restyled too.
- **Signal generator:** a waveform card with a smooth preview, an Output card, and digit-by-digit editors. The Sweep and modulation menu is restyled.
- **Key hints** show the device's own `‖▶` key symbol.

## Testing status

The HW4.0 build has been run on a real HW4.0 unit (shipped with 2.1.0): it boots, and the multimeter works, including live-wire detection. The oscilloscope and generator screens have been checked in pixel-exact renders but need more time on real hardware. Please report anything that looks wrong; a screenshot (long-press `SAVE`) helps.
